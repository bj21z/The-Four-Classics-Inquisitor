# The Four Classics Inquisitor V10.4.1 · 博物馆视觉修复版

## 修复目标
V10.4解决了图片无法加载，却错误地使用文字卡片作为正式展品。V10.4.1将50张馆藏全部替换为独立的国风叙事画面，使博物馆重新具备浏览和观赏价值。
