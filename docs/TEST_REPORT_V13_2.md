## 关键缺陷复现与修复

旧T03题型使用“关于某人物，哪组知识对应正确”，但干扰项来自全书其他真实事实。例如林黛玉题中“前身：绛珠仙草”“代表诗作：《葬花吟》”“父亲：林如海”都可能同时为真，因此不是单题录入错误，而是生成器设计错误。

V13.2改为“关于某人物的某一具体关系，哪一项对应正确”，四个选项全部固定为相同关系，只替换候选值，避免把人物的其他真实属性当作错误答案。
