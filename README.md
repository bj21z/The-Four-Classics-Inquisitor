# The Four Classics Inquisitor V14.0

四大名著阅读、学习、研究与游戏一体化网页程序。

## 已核实的内容规模

- 文字训练题：4000道（每部名著1000道）
- 看图训练题：1000道（每部名著250道）
- 看图资源：50幅馆藏来源图，形成200个“原图×识别视角”组合，每组合5种题法
- 四典游戏馆：8款游戏
- 四典AI阅读馆、教材衔接、人物关系、时间线、路线图、馆藏与学习画像

## V14.0重点

V14.0修复了一个系统性题型错误：旧版“关于某人物，哪组知识对应正确”可能把该人物的多个真实信息同时列为选项，造成多项正确。新版题干限定具体关系，所有选项比较同一关系的不同值，从生成器根源确保唯一正确答案。

同时，V14.0如实区分“题目数量”和“不同图片数量”。1000道看图题不等于1000幅不同图片。

部署和回滚方法见《版本说明.txt》。
