# V14.0 千图真实资源版测试报告

## 设计验证
- 目标：四书各250幅不同文件记录，共1000幅。
- 去重：Wikimedia文件pageid + 文件标题。
- 访问：浏览器只访问本站Cloudflare域名；Worker服务端获取Commons元数据并代理图片。
- 真实性：若任一书不足250幅，API complete=false，界面显示实际数量，不显示“已完成1000幅”。

## 已完成静态检查
- HTML内联JavaScript语法检查。
- Cloudflare Worker语法检查。
- JSON配置文件解析检查。
- ZIP完整性检查。

## 部署后必须进行的在线验收
1. 打开探索中心，点击“建立/刷新千图库”。
2. 核对四书计数是否均为250。
3. 随机抽检每书不少于30幅图片的内容相关性与加载情况。
4. 点击馆藏详情查看来源文件名和说明。
5. 若API未满1000，程序会如实显示实际数量；需要继续调整分类源。

## 已知限制
- 开放馆藏分类内容会随平台更新，首次生成结果可能变化。
- 分类归属保证作品相关，但单幅图片的细粒度人物/事件题需要后续人工标注；V14.0首期采用“对应哪部名著”的唯一答案题型。
- 每张图的具体作者和许可必须以原文件说明页为准。
