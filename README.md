# The Four Classics Inquisitor V11.1 · 权威馆藏接入版

## 设计原则
本版按照“使用中国大陆服务器关联已有作品”的共识重构博物馆。应用本身不复制受保护图片，而是提供权威机构官方平台入口、检索词和资源说明。

## 首批接入
- 国家图书馆 / 中华古籍资源库
- 国家古籍保护中心 / 中国古籍保护网
- 首都图书馆古籍数字资源发布平台
- 云南省古籍数字图书馆

## 使用方式
1. 在应用中选择名著或资源类型。
2. 复制建议检索词。
3. 打开官方平台。
4. 在官方平台搜索并查看原作。

## 为什么不直接嵌入
部分机构明确要求转载、下载或再利用馆藏图片须获得书面许可。直接热链、下载到项目或建立相似数据库可能产生版权与稳定性风险。
